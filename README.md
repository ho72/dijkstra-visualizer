# SWEA 1249 · 보급로

React + TypeScript + Vite로 만든 **27장, 16:9 인터랙티브 웹 발표**입니다.
발표 내용과 기존 자료는 `SWEA_1249_codex_bundle/`에 보존했습니다.

## 실행

```sh
npm install
npm run dev -- --port 5189
```

브라우저에서 `http://localhost:5189`를 엽니다.

```sh
npm test
npm run build
npm run preview -- --port 5189
```

의존성을 설치한 뒤에는 로컬 실행에 인터넷 연결이 필요 없습니다. 운영 빌드는 최초 접속 시 모든 이미지와 Three.js 청크를 Service Worker에 저장합니다. 저장이 완료된 브라우저에서는 오프라인 새로고침도 가능합니다. 처음부터 오프라인인 새 기기, 브라우저 저장 공간을 차단한 환경에서는 로컬 서버를 이용하세요. `dist/index.html`을 `file://`로 직접 여는 방식 대신 HTTP 서버로 제공합니다.

## 발표 조작

| 키                   | 동작                                                 |
| -------------------- | ---------------------------------------------------- |
| → / Space / PageDown | 다음 단계, 마지막 단계에서는 다음 슬라이드           |
| ← / PageUp           | 이전 단계, 첫 단계에서는 이전 슬라이드의 마지막 단계 |
| Home / End           | 처음 / 마지막 슬라이드                               |
| F / Esc              | 전체화면 / 브라우저 전체화면 종료                    |
| R                    | 현재 장면 전체 초기화                                |
| P                    | 현재 장면 자동재생 / 정지                            |
| ?                    | 단축키 도움말                                        |

마우스를 움직이거나 키보드로 컨트롤에 포커스하면 우측 하단의 작은 조작부가 나타납니다. 단계 슬라이더로 임의 시점에 이동할 수 있고, 건너뛰기 버튼으로 현재 장면을 생략할 수 있습니다. 오래된 PQ 후보 장면도 이 버튼으로 건너뜁니다. 자동재생은 현재 장면에서만 동작하며, 다른 탭으로 이동하면 정지합니다.

URL `?scene=13&step=11`처럼 **1-based** 슬라이드·단계 번호로 직접 열 수 있습니다. 현재 위치는 URL에 반영되어 새로고침해도 복원됩니다. 자동재생 여부는 복원하지 않습니다.

## 발표 구성

| 슬라이드 | 내용                                                                 |
| -------- | -------------------------------------------------------------------- |
| 01–04    | 표지 · 문제 상황과 깊이=복구 시간 · 이동 규칙 · 최소 복구 시간       |

| 09–11    | 최소 비용 우선 · dist · Priority Queue                               |
| 12       | 예제 방향 그래프 전체 실행: 26개 스냅샷                              |
| 13–16    | 5→4 갱신 · 갱신 실패 · 11→10 갱신 · 오래된 후보                      |
| 17–19    | 최종 경로 11 · 반복 구조 · Java 템플릿                               |
| 20–22    | Graph→Grid · 좌표/가중치 대응 · 보급로 Java 코드                     |

보급로 격자 실행은 선택·갱신 중심으로 보여줍니다. 생략하지 않은 전체 간선 확인 스냅샷도 `allGridSteps`에 보존되어 있습니다.

## 구현 구조

- `src/app/`: 슬라이드 상태 reducer, 키보드·전체화면·자동재생
- `src/slides/`: 27장 구성, 발표용 Java 코드와 단계 설명
- `src/dijkstra/`: 방향 그래프, 격자 어댑터, 순수 실행 함수, 스냅샷, 검증
- `src/components/`: SVG 그래프·격자, dist, PQ, 비용 비교
- `src/three/`: 그래프→격자 전환에만 사용하는 Three.js 장면
- `src/styles/`: 밝은 배경·큰 한글 제목·제한된 상태색
- `src/build/`: 운영 빌드의 오프라인 캐시 생성
- `public/code/Solution.java`: 컴파일 가능한 SWEA 전체 예제

스냅샷은 서로 배열·객체를 공유하지 않고, PQ 동률은 비용→정점→삽입순으로 결정합니다. 유효 후보를 선택하면 최소 거리를 확정하며, 오래된 후보를 꺼낸 경우에는 dist를 바꾸지 않습니다. 모션은 스냅샷을 표시하는 역할만 합니다.

1920×1080 Stage를 viewport에 contain 스케일링합니다. Three.js는 한 장면만 지연 로딩하며 `frameloop="demand"`로 필요한 전환에만 렌더링합니다. WebGL 실패 시 SVG 대체 화면을 사용합니다. `prefers-reduced-motion` 설정에서는 이동 모션을 최소화합니다.

## 내용상 적용한 판단

- 디자인 충돌은 확정 스타일 가이드를 우선했습니다. 상시 사이드바·대시보드·장식 슬로건은 없습니다.
- 깊이 설명을 02페이지에 통합하여 전체 발표를 27장으로 정리했습니다. 발표자 이름은 제공되지 않아 임의로 기입하지 않았습니다.
- 뒷자리 가독성을 위해 보조 설명은 주로 28–32px, 본문은 32–38px로 확대했습니다. Java 코드는 28px로 통일하고 빈 줄 간격을 줄여 전체 코드가 잘리지 않도록 했습니다. 수치는 1920×1080 Stage 기준입니다.
- 별도 Java 최종본이 없으므로, 문서의 핵심 코드에 PQ 비용 정렬·경계 검사·오래된 후보 제외·입출력을 포함한 실행 가능한 예제를 제공했습니다.
- 기존 도로 깊이·격자 이미지를 재사용했습니다. 알고리즘 그림은 SVG이며 생성 이미지를 추가하지 않았습니다.
- 3D는 개념 대응 장면에만 사용하고, 실제 격자 실행은 선명한 숫자와 약한 높이감을 가진 SVG로 표시합니다.

## 검증

`npm test`는 14개 검증을 수행합니다. 문서의 모든 핵심 갱신, 정확한 간선·PQ 순서·최종 경로, 과거 스냅샷 독립성, 비용 0·순환·단일 칸, 80개 고정 시드 격자와 독립 Bellman–Ford 비교, 이전/다음 역연산, Reset·자동재생·URL 범위를 확인합니다.

Java 예제는 `javac`로 컴파일하고 문서의 3×3 격자, 1×1, 비용 0 격자, 비용이 다른 2×2 격자에서 각각 3, 0, 0, 1을 확인했습니다.

초기 구현에서는 화면 비율, 1920×1080 / 1440×810 / 1024×768에서의 표시, 이전 단계 복원, Reset, 자동재생·정지, Space, Home, 전체화면 F·Esc, 도움말 포커스를 확인했습니다. 운영 미리보기 서버를 실제 중단한 후 새로고침하고 아직 방문하지 않은 Three.js 장면을 열어 오프라인 캐시도 검증했습니다. 글씨 확대 후에는 현재 27장의 마지막 단계에서 콘텐츠 범위를 다시 확인했습니다.
